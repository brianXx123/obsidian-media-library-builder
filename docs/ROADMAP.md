# Roadmap / 路线图

## Implemented in source / 已提交的功能
- CSV/JSON → Markdown, catalog, index and standalone HTML wall
- Native Obsidian plugin under `plugin/`: grid, title search, type/genre/status filters, year/rating sorting, local poster display, detail modal, open note
- Separate persistent watch-status overrides in `user-state.json`
- Non-destructive plugin installation via `install-plugin`
- Bilingual documentation, Skill, Python/Node contract tests and GitHub CI configuration

## Not yet verified / 尚未完成验收
- End-to-end Obsidian desktop installation and real UI screenshot
- Obsidian Mobile (Android/iOS) compatibility and screenshot
- All CI jobs green on both Windows and Linux
- Reimport + manually edited note stress tests and concurrent plugin state writes

## Earlier local build integration / 早期本地版本整合
- Import and review the author's earlier Movie Wall source / 整理并接入作者此前的 Movie Wall 代码
- Compare visual layout, interactions, and data schema against the earlier build / 对照旧版界面与数据格式
- Capture genuine Obsidian screenshots after actual installation / 完成真实安装后截取桌面与手机截图

## Future enhancements / 后续增强
- Optional TMDB matching and licensed poster retrieval with explicit consent and API terms
- Season/episode and collection editors
- Friendlier non-technical import UI, migration and collection-management tools
- Accessibility, large libraries and responsive layout manual QA
