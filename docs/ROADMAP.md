# Roadmap / 后续工作

0.3.0 integrates the original wall and retains its seasons, collections and mobile interactions. Remaining work: broader real-device/iOS/macOS/Linux verification, full UI translation, explicit metadata merge and migration tooling, advanced season/part import, larger-vault profiling and optional virtualization. Metadata/artwork services require explicit user setup and rights checks. Community plugin directory submission is separate from this preview.
