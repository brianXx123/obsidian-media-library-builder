# Roadmap / 开发路线图

## Implemented / 已实现
- CLI import (CSV/JSON) and Markdown note generation / 命令行导入及笔记生成
- Versioned catalog and independent offline HTML preview / 版本化目录与独立 HTML 浏览器预览
- Dry run, collision refusal, basic validation / 试运行、冲突拒绝与基础校验
- Bilingual Skill guidance and documentation / 双语 Skill 文档

- TMDB fetch, poster downloading / TMDB 在线刮削及海报下载
- Drag-and-drop desktop GUI or visual customization / 拖拽桌面配置界面
- Native mobile UI and two-way synchronization / 原生移动 UI 和双向同步
- Season/collection editing / 季、合集编辑
