# Technical Preview v0.1.0-preview / 技术预览

This preview includes a local CSV/JSON importer, Obsidian Markdown notes and index, catalog, offline browser gallery, bilingual Skill and docs, and CI tests. At this initial preview milestone, the native Obsidian plugin had not yet been added and there was no standalone GUI. Genuine Obsidian screenshots were not included.

本版本提供 CSV/JSON 本地导入、Obsidian Markdown 笔记和索引、离线浏览器海报墙、双语 Skill 文档及自动测试。该初始版本尚未包含 Obsidian 原生插件或独立 GUI，也未提供实际 Obsidian 界面截图。
