# 0.3.1 Preview / 预发布

Original project by **brianXx123**. This update completes the desktop demonstration artwork and corrects screenshot evidence. The 24-work desktop vault now has 22 real film posters and 2 official TV publicity photographs, with exact-title and per-file public-domain source checks. No poster source file is included in source, Skill or plugin packages. Missing-poster behavior remains available for users' own incomplete collections.

Actual Windows Obsidian 1.14.5/plugin 0.3.1 screenshots were recaptured after loading every local image. Desktop library, movies, series, detail, filter, Markdown note and the verified light theme are included. **Mobile screenshots remain byte-for-byte the original 0.3.0 captures at the user's request**; they show the separately documented Android demo. The plugin runtime main.js/styles.css are unchanged from the tested 0.3.0 binaries. Only release identity, demo data, documentation and desktop evidence changed.

Python and Node tests, extracted Skill installation, plugin package contents and deterministic cross-platform package rebuilding are required before this preview publishes. Tag `0.3.1` exactly matches both manifests. Attachments: Skill, plugin ZIP, SHA256SUMS.txt, main.js, manifest.json, styles.css. Python 3.10+, Obsidian 1.5.0+. Close Obsidian and back up the vault before `install-plugin --upgrade`.

Known limits remain: primarily Chinese original UI, no automatic metadata/artwork fetching, no automatic private-vault migration or conflict merge, incomplete advanced-season import and no full grid virtualization. Physical Android 0.3.1, iOS, macOS and Linux native UI are NOT RUN. The author's original phone recording was reviewed and extracted locally, with versions unconfirmed. Source and documentation MIT; artwork retains its documented status. This is a preview, not stable 1.0 or a community-directory approval.
