# Demo artwork provenance / 演示海报来源

Checked 2026-10-28. Only file-specific Wikimedia Commons public-domain posters were accepted. Original poster files remain in the isolated local demo and are excluded from this repository and both release packages. No AI-generated poster is used. / 仅使用已逐文件核对的公有领域历史海报；源图片仅留在本地隔离演示库。

The demo contains 24 titles (22 films, 2 series). Modern titles and four unverified historical images use the actual missing-poster fallback. No public ratings, directors, plots or real watch histories are invented. Historical years come from the linked original poster records; the modern works are referenced below. / 共24部作品；未核实海报显示占位，不虚构评分、导演或剧情。
