# Input and recovery / 输入与恢复

Required `title` is text. UTF-8 CSV (including BOM, quoted commas/newlines) and JSON arrays or `{ "items": [...] }` are accepted. Use explicit stable `id` values; autogenerated IDs depend on title, type and year. IDs contain letters, numbers, `.`, `_`, `-`, max 120 characters.

Optional: `type` = `movie`/`tv` (电影/电视剧 accepted), `original_title`, `year` (1880–2200), `genres` (array or comma/semicolon-separated), `rating` (0–10), `rating_source`, `watched` (boolean or recognized text), `overview`, `poster`, `tmdb_id`, `collection_id`, `collection_name`, `collection_original_name`, `collection_order`, `season_count`, `episode_count`, `series_status`, `seasons` (array; CSV uses JSON text).

`seasons`: objects with distinct positive integer `season` numbers (1–300), optional `label`, `status` (`released`/`upcoming`). Unknown episodes and dates stay unknown. Multiple imported works with the same `collection_id` form an original Movie Wall collection automatically. The CLI currently does not import advanced parts/specials or arbitrary original private-vault fields.

`poster` is an existing vault-relative raster image path. Absolute paths, schemes, empty/dot/traversal segments and non-image extensions are rejected. No artwork or metadata network request is made by the importer or plugin.

Notes and watched seasons are authoritative runtime data; the catalog is imported metadata. The plugin edits only watched fields and personal rating through Obsidian's frontmatter API, preserving note text/custom fields. Legacy `user-state.json` status overrides remain readable. Do not manually merge private watch state into public examples.

Identical imports preserve edited notes. Changed metadata for an existing ID, filename collisions, foreign catalogs and unmanaged notes fail before writing. Update protected existing metadata deliberately after a backup; this preview does not provide automatic metadata conflict merging. A `deleted-items.json` tombstone prevents accidental resurrection.

On a write error, the builder rolls back the journaled batch. After interruption, inspect `Media Library/.builder-recovery.json`; run `python scripts/media_library.py recover --vault "VAULT"` to restore the pre-build files. Keep a vault backup, and close Obsidian during bulk import/recovery. Do not run two importers concurrently.

Plugin upgrade: close Obsidian, run `install-plugin --vault "VAULT" --upgrade`. It requires the existing `media-library-wall` manifest and backs up previous plugin files, including `data.json`, under `.obsidian/plugin-backups/`. Only three installation files are replaced. Restore the backup if Obsidian cannot load the update; media notes stay in the vault.

中文：仅 `title` 必填。建议提供固定 ID；电影/剧集、中文、CSV 引号及换行均支持。海报必须是库内已有图片。冲突不覆盖笔记；重复运行保留观看状态和自定义内容。更新已有元数据需备份后明确处理，本预览版不自动合并冲突。异常中断时先检查恢复日志，再执行 `recover`。批量导入或恢复时关闭 Obsidian，不要并发运行。升级插件使用 `--upgrade`，旧插件文件会备份在库内，媒体数据不删除。
